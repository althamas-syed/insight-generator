# Security policy

Insight Generator processes CSV data locally in the browser. This is a design goal, not a guarantee that every deployment or third-party extension is secure.

Do not submit sensitive datasets, access tokens, or credentials in public issues.

To report a potential vulnerability privately, use GitHub's **Report a vulnerability** option under the repository's Security tab if enabled. Otherwise, contact the maintainer privately through their GitHub profile rather than publishing exploit details.

Supported versions: the current main branch is the development target. Security fixes are provided on a best-effort basis.
