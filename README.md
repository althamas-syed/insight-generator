# Insight Generator

A free, in-browser tool that takes a messy CSV and:
- Scans it for data quality issues (duplicates, missing values, inconsistent casing, invalid negatives)
- Auto-cleans it and shows a before/after data quality score
- Generates role-specific insight reports (Data Analyst / Data Scientist / Business Analyst view)
- Proposes adaptive deep-dive analyses based on the specific shape of your dataset
- Lets you ask follow-up questions about your data
- Lets you download the cleaned CSV and the generated report

Everything runs **entirely client-side** — no backend, no API key, no cost. All "insights" are generated by a local statistics + rules engine reading your data's actual computed values (means, correlations, outlier counts, etc.), not an external AI service.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL it prints (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview   # to test the production build locally
```

This outputs a `dist/` folder — a fully static site you can host anywhere.

## Deploy for free

### Option A — Vercel (recommended, easiest)
1. Push this project to a GitHub repo
2. Go to [vercel.com](https://vercel.com), sign in with GitHub
3. Click "New Project", select your repo
4. Vercel auto-detects Vite — click Deploy
5. You get a live URL like `insight-generator-yourname.vercel.app`

### Option B — Netlify
1. Push to GitHub
2. Go to [netlify.com](https://netlify.com) → "Add new site" → "Import an existing project"
3. Build command: `npm run build`, publish directory: `dist`
4. Deploy — you get a URL like `insight-generator.netlify.app`

### Option C — GitHub Pages
1. In `vite.config.js`, set `base: "/your-repo-name/"`
2. Run `npm run build`
3. Push the `dist/` folder contents to a `gh-pages` branch (or use the `gh-pages` npm package)
4. Enable GitHub Pages in repo settings, pointing to that branch

## Tech stack
- React 18 + Vite
- PapaParse (CSV parsing)
- lucide-react (icons)
- No backend, no database, no API keys
